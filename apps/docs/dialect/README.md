# 设计稿方言

把 Figma 插件导出的快照变成一个代码 repo，让 agent 用读写代码的方式读懂、修改设计稿。代码借 React Native 的外形：`View`、`Text`、`Image` 和 `style` 里的键与 RN 同名同义，Figma 独有的写成 `fg-` 属性和 `Fg.` 元素。代码里只写设计师定的值，Figma 算出来的尺寸和位置由我们的排版引擎重算。检查时把代码解析回快照，和原来的快照逐字段比，目标是 203 个用例零差别。现在只有设计，还没开工；代码画到画布上、画布改动写回代码是后面的步骤（[产品方向](../product-direction/README.md)的路线第 4、5 步）。

## 关键决定

- 设计稿以代码为准，方言借 RN 的外形、按 Figma 的意思；不回 Figma（用户拍板，2026-10-30，见 [产品方向 product.md §2](../product-direction/product.md#2-已经定下的事2026-10-30)）
- 只写意图、不写结果：包裹内容的尺寸、自动布局里的位置、组的框不进代码，打开时重排；重排后还原度掉多少阶段 0 先测（建议，用户未确认，2026-10-31，见 [tech.md §2](tech.md#2-只写意图不写结果2026-10-31)）
- `fg-` 后面接 Figma 导出数据（REST）里的字段名，取值照写；没专门设计写法的字段也按这条原样写出（建议，待用户定，2026-10-31，见 [tech.md §3.1](tech.md#31-fg--属性的命名规则建议待用户定)）
- 旋转镜像写成 RN 的 `transform`，不用矩阵（建议，修订产品方向的说法，2026-10-31，见 [tech.md §4.5](tech.md#45-旋转和镜像)）
- 覆盖按主组件里图层的 id 写，值的写法和元素上一样（2026-10-31，见 [tech.md §8.3](tech.md#83-覆盖)）
- 样式的值从用到它的图层反推，不改插件：203 个样式的所有用处取值都一样（2026-10-31 实测，见 [tech.md §9.1](tech.md#91-样式的值从用到它的图层反推)）
- 反方向解析代码、不执行（2026-10-31，见 [tech.md §13](tech.md#13-求值器和往返比较2026-10-31)）
- 代码先放 `apps/client/src/dialect/`，不建新包（建议，用户未确认，2026-10-31，见 [tech.md §14](tech.md#14-代码放在哪和现有代码的关系2026-10-31)）
