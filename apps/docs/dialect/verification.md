## 3. 手动验收清单

1. 打开 `designs/untitled-ui-…/pages/<页>/_index.md` → 列出这一页的屏幕、尺寸、节点数、用到的组件。
2. 打开一个屏幕的 `index.tsx` → 结构和 Figma 的图层树对得上；实例只有一行；覆盖的 key 后面有图层名注释。
3. 打开 `components/button.*/index.ts` → 变体是联合类型；把一个实例的变体改成不存在的值，`tsc --noEmit` 报错。
4. 找一个绑了样式的图层 → 写的是 `t.fill['…']` 之类，名字和 Figma 里一样；没绑的写的是数值。
5. 找一个包裹内容的 frame → `style` 里没有它的宽或高。
6. 看报告里"原样写出的字段" → 都是 tech.md §11 表里最后一类，没有漏掉不认识的。
