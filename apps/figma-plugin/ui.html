Fidelity 测试用例

先生成用例，再导出测试数据。

1. 生成测试用例 在 “Test Cases” 页面上画出所有用例。下面填了前缀（如 text-mixed/）时只画名字以它开头的用例，画在 “Test Cases · text-mixed” 页面上（取前缀的第一段）。页面已经有了就接着用，同名的用例换成新画的。
2. 导出测试数据 导出当前页面的顶层 frame（有选中时只导出选中的），打包成 zip。
3. 按列表导出 贴一段 JSON：[{"id": "节点 id", "dir": "用例目录"}…]，按 id 找节点、按给定目录导出。用来原样重新导出已有的用例。
4. 量图片滤镜 让 Figma 给一张色表图套上 7 种图片调整的各个档位并导出，打包成 zip，用来在网页里还原这些调整。不改任何页面（临时建的矩形导完就删）。
